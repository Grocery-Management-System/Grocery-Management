# HOW TO RUN

## Setup
1. Clone the repo
2. Open in IntelliJ
3. Set Project SDK if needed
4. Run the project

## Requirements:
SDK: openjdk-25
Language Level: 21 - Record patterns, pattern matching for switches
Framework: JavaFX

### Important: If project doesn't run, make sure to check JavaFX is properly configured in your IDE
